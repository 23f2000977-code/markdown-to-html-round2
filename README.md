# Markdown to HTML Converter

This is a simple web application that converts Markdown text into HTML. It provides a user-friendly interface to enter Markdown content and see the rendered HTML output in real-time.

## Features

- **Markdown to HTML Conversion**: Input Markdown text and see the corresponding HTML output.
- **Live Word Count**: Displays the word count of the entered Markdown text, formatted with commas for better readability.

## How to Use

1. Enter your Markdown text in the provided textarea.
2. The converted HTML output will be displayed below.
3. The word count will update automatically as you type.

## Technologies Used

- HTML
- CSS (Bootstrap)
- JavaScript (Marked.js for Markdown processing, Highlight.js for syntax highlighting)

## Live Demo

You can try the application directly by opening the `index.html` file in your browser.
